# Palette's Journal 🎨

> "Good UX is invisible - it just works"

This journal tracks critical UX and accessibility learnings, surprising user behaviors, and reusable patterns.

## 2024-05-14 - Auto-clear error state and restore focus
**Learning:** Automatically restoring focus to the input field on error and clearing the error state as the user begins typing significantly improves the recovery experience.
**Action:** Always shift focus programmatically and remove error styling dynamically when a user corrects input values.
